# Alfy-diagnose

강아지 피부질환 진단을 위한 Python 기반 API 서버입니다.  
사용자가 반려견의 피부 이미지를 업로드하면, AI 모델을 통해 피부 상태를 분석하고 진단 결과를 반환합니다.

이 프로젝트는 AI-Hub에서 제공하는 반려동물 피부질환 데이터셋과 모델을 활용하여 개발되었습니다.

---

## Introduction

반려견은 피부질환이 비교적 흔하게 나타나는 동물이며, 초기 증상을 빠르게 확인하는 것이 중요합니다.  
본 프로젝트는 반려견 피부 이미지를 기반으로 피부질환 여부 및 증상 유형을 예측할 수 있도록 설계된 AI 진단 API입니다.

사용자는 피부 사진을 업로드하고, 서버는 학습된 모델을 이용해 이미지를 분석한 뒤 예측 결과를 반환합니다.  
이를 통해 보호자가 반려견의 피부 상태를 보다 쉽게 확인하고, 이상 징후를 조기에 인지할 수 있도록 돕는 것을 목표로 합니다.

---

## Features

- 반려견 피부 이미지 업로드
- AI 기반 피부질환 분류
- 예측 결과 반환
- 정상 / 질환 의심 여부 판별
- 피부 증상 유형 분류
- API 형태로 모델 추론 기능 제공

---

## Labels

본 프로젝트는 다음과 같은 피부 증상 분류를 기반으로 동작합니다.

- A1: 구진 / 플라크
- A2: 비듬 / 각질 / 상피성잔고리
- A3: 태선화 / 과다색소침착
- A4: 농포 / 여드름
- A5: 미란 / 궤양
- A6: 결절 / 종괴
- 정상 (무증상)

- Python
- FastAPI / Flask

- Deep Learning Model for Dog/Cat Skin Disease Classification

## Dataset and Model

본 프로젝트는 **AI-Hub에서 제공하는 반려동물 피부질환 관련 데이터셋과 모델**을 활용하였습니다.  
강아지 피부 이미지 데이터를 기반으로 학습된 모델을 사용하여 피부 증상을 분류합니다.
